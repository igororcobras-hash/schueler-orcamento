# Schueler Orçamento Analítico

Programa de orçamento de obras (versão V1-02-32). Endereço: https://orcamento.totalcivil.com.br/

## Acesso (V1-02-32)
Login em nuvem (Firebase, projeto calculadora-dnit): entra com apelido ou e-mail, recupera a senha por e-mail e o cadastro novo fica pendente até um administrador autorizar no painel "Usuários". A conta é a mesma dos demais programas Total Civil; a liberação do Orçamento é separada (campo `orcamentoAtivo`).
